BUG-01 HIGH Engine stocks/config.py
Float precision trong validate_price() — modulo trên float trả 1e-12 thay vì 0, từ chối lệnh hợp lệ.
✓ FIX & REASONING
remainder = round(
  (price-floor)%step, 6
)
→ or abs(rem-step) < 1e-9
IEEE 754 — epsilon tolerance thay so sánh exact
BUG-02 MEDIUM API/WS state.py
WS market_data_clients set không thread-safe — iterate đồng thời disconnect → RuntimeError: Set changed size.
✓ FIX & REASONING
for ws in list(clients):
  try: await ws.send_json(m)
  except: clients.discard(ws)
list() snapshot tại iterate, auto-cleanup stale conn
BUG-03 MEDIUM FIX Layer fix/server.py
MARKET order CANCEL thiếu OrdStatus=4 tag trong ExecutionReport — FIX client không parse được status.
⏳ PENDING — plan
msg.append(44, b"4")  # ExecType
+msg.append(39, b"4") # OrdStatus
FIX 4.4 spec: ExecType + OrdStatus cả hai bắt buộc
BUG-04 HIGH API/WS order_book.py · ws.py

def get_snapshot(self, cfg=None):
