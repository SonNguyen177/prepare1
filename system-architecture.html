Luồng xử lý chi tiết — Ví dụ: Mua VCK 200 @ 12,000

1
Người dùng đặt lệnh
  • Mở Client Terminal :5173
  • Nhập VCK · BUY · LIMIT · qty=200 · price=12000
  • Áp dụng cho cả nhà đầu tư lẻ và tổ chức
2
Quản trị viên giám sát
  • Admin Panel :3001 kết nối
  • ws://:8000/ws/admin → full init state
  • Xem sổ lệnh, log, đếm client realtime
  • Cấu hình Floor / Ceil / Step cho từng mã
3
FIX TCP Server nhận lệnh
  • Client gửi NewOrderSingle (D) tới :9876
  • FIX Handler parse message FIX 4.4
  • Kiểm tra Logon · Sequence · Heartbeat
  • Chuyển sang match_order() Engine
4
Engine Validation & Routing
  • Kiểm tra: 10000 ≤ 12000 ≤ 15000 ✓
  • Bước giá: 12000 % 100 == 0 ✓
  • Bước KL: 200 % 100 == 0 ✓
  • Định tuyến vào OrderBook[VCK]
5
Khớp lệnh (OrderBook VCK)
  • Quét Asks: Sell 12000 ≥ Bid 12000 → khớp!
  • Giá khớp = maker price (12,000)
  • Cả 2 lệnh → FILLED, rời sổ lệnh
  • Tạo Trade với sequence number
6
Broadcast kết quả
  • FIX Server gửi ExecutionReport FILLED về Client
  • client ws://:8765 push Trade mới tới Client Terminal
  • Admin Panel: Trade History + Logs cập nhật
  • Sequenced → có thể replay để recover state
